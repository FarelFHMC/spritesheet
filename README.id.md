# Spritesheet Studio

[English](README.md) | Bahasa Indonesia

Aplikasi web kecil untuk mengubah video, GIF, dan gambar menjadi spritesheet. Bisa edit frame, hapus background, gabung dua sheet atau lebih, lalu export sebagai gambar atau animasi, atau membuat font pixel sendiri dan mengekspornya sebagai TTF. Semuanya jalan 100% di browser: HTML, CSS, dan JavaScript biasa, tanpa build, tidak ada file yang diunggah ke server.

Versi 2.7 · [Changelog](CHANGELOG.id.md) · [Lisensi MIT](LICENSE)

## Cara pakai

Buka aplikasinya (online lewat GitHub Pages, atau buka `index.html` di perangkatmu). Tab berurutan:

1. **Import** — masukkan video (MP4/WebM/MOV), GIF, atau gambar. Untuk video, atur FPS (atau interval), waktu mulai/akhir, maks frame, dan ukuran frame, lalu **Ekstrak Frame**. Untuk GIF, **Decode GIF**. Untuk gambar, **Tambahkan ke Frame**.
2. **Background** (opsional) — pilih **Hapus warna spesifik** atau **Chroma Key**. Klik gambar asli untuk ambil warna, atau tekan **Deteksi dari pojok**. Atur *Tolerance* (seberapa mirip warna yang ikut hilang) dan *Feather* (tepi halus). Tekan **Terapkan**; kalau hasilnya jelek, **Urungkan**.
3. **Spritesheet** — atur ukuran frame, kolom, padding, margin, lalu **Bangun Spritesheet**.
4. **Editor** — mengatur frame. Seret kartu untuk mengubah urutan (di ponsel, tahan kartu sebentar lalu seret), atau pakai ◀ ▶. Seret file gambar dari perangkatmu ke halaman untuk menambahnya sebagai frame. **+ Tambah Gambar** memilih gambar, **+ Frame Kosong** menambah frame transparan kosong, × menghapus. Lalu **Rebuild**.
5. **Paint Sprite** — gambar sprite memenuhi layar. Toolbar melayang yang ringkas ada tepat di bawah hamburger dan tidak memanjang: baris atas berisi tiga kategori (**Alat**, **Layer**, **Lihat**), kotak warna, dan urungkan / ulangi; baris di bawahnya berubah sesuai kategori.
   - **Alat:** **Brush**, **Eraser**, **Fill**, **Eyedrop**, **Laso**, **Geser**. Ketuk **Brush**, **Eraser**, **Fill**, atau **Laso** untuk membuka pengaturannya (ketuk lagi untuk menutup). Brush dan Eraser masing-masing punya *Ukuran* sendiri (1–64 px). **Fill** punya *Tolerance* (0–255: seberapa beda warna yang masih ikut terisi; 0 = persis sama), *Area isi* (**Terhubung** = hanya area yang menyambung, **Semua warna** = semua piksel yang cocok di frame), dan *Ambil warna dari* (**Layer ini** atau **Semua layer**). Kotak warna membuka **lingkaran warna** (seret cincin untuk memilih warna, kotak di dalamnya untuk kejenuhan dan kecerahan), kolom hex, dan warna cepat.
   - **Laso:** gambar area bebas di sekeliling bagian yang kamu mau. *Mode laso* mengatur cara area baru digabung dengan yang lama: **Baru** (mengganti), **Tambah**, atau **Kurangi**; ketuk sekali di mode *Baru* untuk membatalkan pilihan. Area tampak sebagai garis putus-putus, dan aksinya bekerja pada piksel *layer terpilih* di dalamnya: **Pisah ke layer baru** (dipotong), **Salin ke layer baru**, **Hapus isi**, **Balik pilihan**, dan **Batal pilih**. **Geser / Putar / Ubah ukuran** mengubah piksel terpilih menjadi kotak yang bisa diseret untuk menggeser, ditarik di sudut atau sisi untuk mengubah ukuran, dan diputar dengan titik bulat (Shift = per 15°); lebar, tinggi, dan sudut juga bisa diketik, **Terapkan** (Enter) mengonfirmasi dan **Batal** (Esc) membuangnya. Tidak pernah buram: setiap piksel disalin dari aslinya tanpa pelembutan dan tanpa warna baru. Pintasan: L Laso, Esc batal pilih, Delete menghapus piksel terpilih, tombol panah menggeser saat transformasi.
   - **Layer:** setiap frame bisa punya beberapa layer. **+ Layer** menambah satu di atas layer yang aktif; daftarnya menampilkan layer teratas lebih dulu. Centang kotak untuk menampilkan / menyembunyikan layer, ketuk layer untuk menggambar di atasnya, ketuk namanya lagi untuk mengganti nama, ↑ ↓ mengubah urutan, × menghapus (minimal 1 tersisa). **Duplikat**, **Gabung ke bawah**, dan slider *Opasitas* ada di panel yang sama. Maksimal 16 layer per frame. Mengetuk sprite menutup panel supaya kamu langsung bisa menggambar. Layer hanya alat bantu menggambar: sheet, ZIP, dan JSON selalu memakai gambar gabungan dari layer yang terlihat.
   - **Smart Split:** di panel Layer, **Smart Split** memisahkan layer terpilih menjadi beberapa layer baru secara otomatis. *Pisah berdasarkan* **Bagian terpisah** (piksel yang bersentuhan tetap satu; *Jarak gabung* juga menyatukan bagian yang berdekatan, misalnya mata yang melayang di dekat wajah) atau **Warna** (warna yang mirip dikelompokkan; *Toleransi warna* mengatur seberapa mirip). *Abaikan bintik kurang dari* mengumpulkan potongan sangat kecil ke satu layer bernama **Sisa**. Kalau ada area terpilih dari Laso, kamu bisa memisahkan area itu saja. **Simpan layer asli** menyimpannya (disembunyikan). Tidak pernah melewati 16 layer: potongan terkecil digabung ke Sisa. Urungkan mengembalikan layer dalam satu langkah.
   - **Lihat:** zoom dengan − / + (atau Ctrl + scroll mouse), **Fit** mengembalikannya.
   Bar frame melayang di bagian bawah menampilkan semua frame: ketuk satu untuk menggambar di atasnya, **+** menambah frame kosong setelah frame terpilih, dan kolom di bawahnya mengatur nama frame (dipakai sebagai nama file saat export). Urungkan / ulangi (Ctrl+Z / Ctrl+Y) mencakup coretan, fill, dan semua perubahan layer. Pintasan: B Brush, E Eraser, G Fill, I Eyedrop, L Laso, H Geser. Kuasnya persegi tanpa anti-alias, cocok untuk pixel art. Catatan: memakai **Background → Terapkan** pada sebuah frame akan meratakan layernya menjadi satu.
6. **Player** — memutar frame sebagai animasi. **Putar / Jeda**, frame sebelumnya / berikutnya, dan slider untuk menggeser posisi. *Kecepatan* 1–60 FPS, *Mode putar* (**Ulang**, **Bolak-balik**, **Sekali**), *Skala* (**Fit**, 1×–8×), *Latar* (**Checker**, **Gelap**, **Terang**), dan **Dari frame / Sampai frame** untuk mengulang sebagian animasi saja. Pintasan: Spasi putar / jeda, ← → pindah frame. Tombol ▶ di bar frame Paint Sprite membukanya langsung.
7. **Font Creator** — buat font pixel-mu sendiri, huruf demi huruf. Pilih karakter (ketuk di grid, atau pakai ‹ ›), lalu gambar atau hapus di grid besar; **Urungkan / Ulangi** (Ctrl+Z / Ctrl+Y), panah **Geser huruf**, **Kosongkan**, dan **Kembalikan ke klasik** ada tepat di bawahnya. Garis hijau adalah garis dasar: baris di atasnya badan huruf, baris di bawahnya ekor huruf (g, j, p, q, y). **Huruf yang tidak pernah kamu gambar otomatis memakai font klasik 5×7 bawaan** (spasi, angka, A–Z, a–z, dan tanda baca, ASCII 32–126), jadi font selalu lengkap; titik hijau pada karakter berarti itu buatanmu. **Tambah karakter lain** (é, ñ, ü ...) lewat kolom di bawah grid; karakter tambahan yang tetap kosong tidak ikut diekspor. *Pengaturan Font*: nama font, lebar / tinggi huruf (1–32 px), garis dasar, jarak antar huruf, dan lebar *proporsional* (opsional). Mengubah ukuran tidak menghapus gambarmu. **Pratinjau** langsung menampilkan teksmu. **Export Font** membuat satu **ZIP** berisi **font TrueType (.ttf)** yang bisa diinstal, **bitmap font** untuk game engine (`nama.png` + `nama.fnt` format teks BMFont), file **JSON** berisi ukuran tiap huruf, opsional satu PNG per huruf, dan README singkat. **Download TTF saja** hanya memberi file font. TTF dibuat di dalam aplikasi dengan outline piksel yang tajam dan tanpa celah: pakai di ukuran sama dengan tinggi huruf (mis. 9 px) atau kelipatannya agar tepinya tajam. Tidak ada yang diunggah.
8. **Gabung** — muat **2 spritesheet atau lebih** (**+ Tambah Spritesheet**, sampai 12; ↑ ↓ mengubah urutan, × menghapus satu) lalu gabung horizontal, vertikal, overlay, atau tambahkan frame-nya. Di **Append Frames** tiap spritesheet punya *Lebar / Tinggi frame* sendiri (dan menampilkan jumlah frame-nya), dan hasilnya bisa diexport bersama JSON metadata.
9. **Export** — isi **Nama file**, pilih **PNG / JPG / WebP** (JPG dan WebP punya slider kualitas; JPG mengisi area transparan dengan warna latar pilihanmu), lalu unduh spritesheet, **semua frame jadi satu ZIP** (atau satu per satu), atau JSON metadata (posisi dan nama frame). Kalau frame berubah setelah sheet dibangun, Export membangunnya ulang otomatis.
   **Export animasi** (kartu kedua di tab Export): buat **GIF**, **WebP animasi**, atau video **MP4** dari frame. Atur *Kecepatan* (1–60 FPS), *Ukuran* (1×–8×, skala bilangan bulat), *Mode putar* (**Ulang**, **Bolak-balik**, **Sekali**), *Dari / Sampai frame* (kosong = pertama / terakhir), dan **Latar transparan** (GIF dan WebP) atau warna latar. GIF memakai paling banyak 255 warna dan transparansi ada-atau-tidak; WebP mempertahankan transparansi penuh (kualitas 100 = paling tajam); MP4 tidak punya transparansi dan butuh browser dengan WebCodecs (Chrome, Edge, atau Safari terbaru). Frame yang ukurannya berbeda diletakkan di tengah. Nama file: `nama_anim.gif` / `.webp` / `.mp4`. Semua dibuat di dalam aplikasi: tanpa library, tidak ada yang diunggah.

**Pixelated vs Smoothed** (kanan atas). *Pixelated* tidak pernah mencampur warna: paling cocok untuk pixel art. *Smoothed* merata-ratakan warna saat diperkecil dan menghaluskan saat diperbesar: lebih cocok untuk foto/video. Pengaturan ini berlaku saat frame diekstrak atau sheet dibangun, jadi bangun ulang setelah mengubahnya.

**Tips.** Untuk video pakai ukuran frame kecil (mis. 64–128 px). FPS lebih rendah = frame lebih sedikit dan rapi. Semua data hanya di memori; refresh halaman menghapus frame dan font-mu.

## Jalankan lokal
Buka `index.html` di browser. Tidak perlu instal apa pun.

## Deploy ke GitHub Pages (untuk pemula)
1. Buat akun di github.com, lalu tekan **+ → New repository**. Beri nama (mis. `spritesheet-studio`), pilih **Public**, klik **Create repository**.
2. Klik **uploading an existing file** (atau **Add file → Upload files**). Unggah *isi* folder proyek (`index.html`, `style.css`, `app.js`, `README.md`, `README.id.md`, `LICENSE`, `CHANGELOG.md`, `CHANGELOG.id.md`). Ekstrak ZIP dulu, jangan unggah ZIP-nya. Klik **Commit changes**.
3. Buka **Settings → Pages**. Di *Build and deployment*, Source: **Deploy from a branch**, Branch: **main**, folder **/ (root)**, lalu **Save**.
4. Tunggu 1–2 menit. Situsmu: `https://<username>.github.io/<nama-repo>/`.

Untuk update nanti: buka file di repo, klik ikon pensil, edit, lalu commit — atau unggah ulang file dengan nama yang sama.
