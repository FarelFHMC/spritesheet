# Spritesheet Studio

[English](README.md) | Bahasa Indonesia

Aplikasi web kecil untuk mengubah video, GIF, dan gambar menjadi spritesheet. Bisa edit frame, hapus background, gabung dua sheet atau lebih, lalu export sebagai gambar atau animasi, simpan dan buka lagi pekerjaanmu dalam folder, membuat font pixel sendiri dan mengekspornya sebagai TTF, menulis dokumen desain game di editor bawaan, atau menggubah lagu dan efek suara di studio bawaan. Semuanya jalan 100% di browser: HTML, CSS, dan JavaScript biasa, tanpa build, tidak ada file yang diunggah ke server.

## Cara pakai

Buka aplikasinya (online lewat GitHub Pages, atau buka `index.html` di perangkatmu). Tab berurutan:

1. **Import** — masukkan video (MP4/WebM/MOV), GIF, atau gambar. Untuk video, atur FPS (atau interval), waktu mulai/akhir, maks frame, dan ukuran frame, lalu **Ekstrak Frame**. Untuk GIF, **Decode GIF**. Untuk gambar, **Tambahkan ke Frame**. Gambar boleh sampai **16384 px** per sisi (dan 100 juta piksel secara keseluruhan); gambar yang lebih besar dilewati dengan pesan, bukan membuat aplikasi rusak.
2. **Background** (opsional) — pilih **Hapus warna spesifik** atau **Chroma Key**. Klik gambar asli untuk ambil warna, atau tekan **Deteksi dari pojok**. Atur *Tolerance* (seberapa mirip warna yang ikut hilang) dan *Feather* (tepi halus). Tekan **Terapkan**; kalau hasilnya jelek, **Urungkan**.
3. **Spritesheet** — atur ukuran frame, kolom, padding, margin, lalu **Bangun Spritesheet**. Sheet paling besar **16384 px** per sisi (100 juta piksel secara keseluruhan), batas terbesar yang bisa digambar browser; kalau sheet-mu lebih besar akan muncul pesan, jadi pakai kolom lebih sedikit atau frame lebih kecil.
4. **Editor** — mengatur frame. Seret kartu untuk mengubah urutan (di ponsel, tahan kartu sebentar lalu seret), atau pakai ◀ ▶. Seret file gambar dari perangkatmu ke halaman untuk menambahnya sebagai frame. **+ Tambah Gambar** memilih gambar, **+ Frame Kosong** menambah frame transparan kosong, × menghapus. Lalu **Rebuild**.
5. **Paint Sprite** — gambar sprite memenuhi layar. Toolbar melayang yang ringkas ada tepat di bawah hamburger dan tidak memanjang: baris atas berisi tiga kategori (**Alat**, **Layer**, **Lihat**), kotak warna, dan urungkan / ulangi; baris di bawahnya berubah sesuai kategori. Di ponsel, tombol kecil **▲** di ujung baris atas menyembunyikan semua yang ada di bawah baris itu supaya seluruh sprite terlihat; ketuk lagi untuk memunculkan toolbar. Panel pengaturan, layer, dan laso tidak pernah memakai lebih dari sekitar sepertiga layar.
   - **Alat:** **Brush**, **Eraser**, **Fill**, **Eyedrop**, **Laso**, **Geser**. Ketuk **Brush**, **Eraser**, **Fill**, atau **Laso** untuk membuka pengaturannya (ketuk lagi untuk menutup). Brush dan Eraser masing-masing punya *Ukuran* sendiri (1–64 px). **Fill** punya *Tolerance* (0–255: seberapa beda warna yang masih ikut terisi; 0 = persis sama), *Area isi* (**Terhubung** = hanya area yang menyambung, **Semua warna** = semua piksel yang cocok di frame), dan *Ambil warna dari* (**Layer ini** atau **Semua layer**). Kotak warna membuka **lingkaran warna** (seret cincin untuk memilih warna, kotak di dalamnya untuk kejenuhan dan kecerahan), kolom hex, dan warna cepat.
   - **Laso:** gambar area bebas di sekeliling bagian yang kamu mau. *Mode laso* mengatur cara area baru digabung dengan yang lama: **Baru** (mengganti), **Tambah**, atau **Kurangi**; ketuk sekali di mode *Baru* untuk membatalkan pilihan. Area tampak sebagai garis putus-putus, dan aksinya bekerja pada piksel *layer terpilih* di dalamnya: **Pisah ke layer baru** (dipotong), **Salin ke layer baru**, **Hapus isi**, **Balik pilihan**, dan **Batal pilih**. **Geser / Putar / Ubah ukuran** mengubah piksel terpilih menjadi kotak yang bisa diseret untuk menggeser, ditarik di sudut atau sisi untuk mengubah ukuran, dan diputar dengan titik bulat (Shift = per 15°); lebar, tinggi, dan sudut juga bisa diketik, **Terapkan** (Enter) mengonfirmasi dan **Batal** (Esc) membuangnya. Tidak pernah buram: setiap piksel disalin dari aslinya tanpa pelembutan dan tanpa warna baru. Pintasan: L Laso, Esc batal pilih, Delete menghapus piksel terpilih, tombol panah menggeser saat transformasi.
   - **Layer:** setiap frame bisa punya beberapa layer. **+ Layer** menambah satu di atas layer yang aktif; daftarnya menampilkan layer teratas lebih dulu. Centang kotak untuk menampilkan / menyembunyikan layer, ketuk layer untuk menggambar di atasnya, ketuk namanya lagi untuk mengganti nama, ↑ ↓ mengubah urutan, × menghapus (minimal 1 tersisa). **Duplikat**, **Gabung ke bawah**, dan slider *Opasitas* ada di panel yang sama. Maksimal 16 layer per frame. Mengetuk sprite menutup panel supaya kamu langsung bisa menggambar. Layer hanya alat bantu menggambar: sheet, ZIP, dan JSON selalu memakai gambar gabungan dari layer yang terlihat.
   - **Smart Split:** di panel Layer, **Smart Split** memisahkan layer terpilih menjadi beberapa layer baru secara otomatis. *Pisah berdasarkan* **Bagian terpisah** (piksel yang bersentuhan tetap satu; *Jarak gabung* juga menyatukan bagian yang berdekatan, misalnya mata yang melayang di dekat wajah) atau **Warna** (warna yang mirip dikelompokkan; *Toleransi warna* mengatur seberapa mirip). *Abaikan bintik kurang dari* mengumpulkan potongan sangat kecil ke satu layer bernama **Sisa**. Kalau ada area terpilih dari Laso, kamu bisa memisahkan area itu saja. **Simpan layer asli** menyimpannya (disembunyikan). Tidak pernah melewati 16 layer: potongan terkecil digabung ke Sisa. Urungkan mengembalikan layer dalam satu langkah.
   - **Lihat:** zoom dengan − / + (atau Ctrl + scroll mouse), **Fit** mengembalikannya. **Onion skin** membuka pengaturan onion (lihat di bawah).
   - **Onion skin:** menampilkan frame sebelum dan sesudah frame yang sedang digambar sebagai bayangan samar di belakangnya, untuk membantu menggambar gerakan. Aktifkan dengan tombol di bar frame (di sebelah ▶), dengan tombol **O**, atau dengan *Aktifkan onion skin* di pengaturannya. Pengaturan: *Frame sebelumnya / sesudahnya* (0–5), *Opasitas bayangan*, *Makin jauh makin pudar*, *Sambung dari akhir ke awal (loop)*, dan *Beri warna pembeda* (merah = sebelum, biru = sesudah). Hanya tampilan: tidak pernah ikut ke sheet, ZIP, JSON, atau export apa pun.
   Bar frame melayang di bagian bawah menampilkan semua frame (kalau frame banyak, bar tetap di dalam kotaknya dan bisa digeser ke samping: geser dengan jari, atau pakai roda mouse): ketuk satu untuk menggambar di atasnya, **+** menambah frame kosong setelah frame terpilih, dan kolom di bawahnya mengatur nama frame (dipakai sebagai nama file saat export). Urungkan / ulangi (Ctrl+Z / Ctrl+Y) mencakup coretan, fill, dan semua perubahan layer. Pintasan: B Brush, E Eraser, G Fill, I Eyedrop, L Laso, H Geser. Kuasnya persegi tanpa anti-alias, cocok untuk pixel art. Catatan: memakai **Background → Terapkan** pada sebuah frame akan meratakan layernya menjadi satu.
6. **Player** — memutar frame sebagai animasi. **Putar / Jeda**, frame sebelumnya / berikutnya, dan slider untuk menggeser posisi. *Kecepatan* 1–60 FPS, *Mode putar* (**Ulang**, **Bolak-balik**, **Sekali**), *Skala* (**Fit**, 1×–8×), *Latar* (**Checker**, **Gelap**, **Terang**), dan **Dari frame / Sampai frame** untuk mengulang sebagian animasi saja. Pintasan: Spasi putar / jeda, ← → pindah frame. Tombol ▶ di bar frame Paint Sprite membukanya langsung.
7. **Font Creator** — buat font pixel-mu sendiri, huruf demi huruf. Pilih karakter (ketuk di grid, atau pakai ‹ ›), lalu gambar atau hapus di grid besar; **Urungkan / Ulangi** (Ctrl+Z / Ctrl+Y), panah **Geser huruf**, **Kosongkan**, dan **Kembalikan ke klasik** ada tepat di bawahnya. Garis hijau adalah garis dasar: baris di atasnya badan huruf, baris di bawahnya ekor huruf (g, j, p, q, y). **Huruf yang tidak pernah kamu gambar otomatis memakai font klasik 5×7 bawaan** (spasi, angka, A–Z, a–z, dan tanda baca, ASCII 32–126), jadi font selalu lengkap; titik hijau pada karakter berarti itu buatanmu. **Tambah karakter lain** (é, ñ, ü ...) lewat kolom di bawah grid; karakter tambahan yang tetap kosong tidak ikut diekspor. *Pengaturan Font*: nama font, lebar / tinggi huruf (1–32 px), garis dasar, jarak antar huruf, dan lebar *proporsional* (opsional). Mengubah ukuran tidak menghapus gambarmu. **Pratinjau** langsung menampilkan teksmu. **Export Font** membuat satu **ZIP** berisi **font TrueType (.ttf)** yang bisa diinstal, **bitmap font** untuk game engine (`nama.png` + `nama.fnt` format teks BMFont), file **JSON** berisi ukuran tiap huruf, opsional satu PNG per huruf, dan README singkat. **Download TTF saja** hanya memberi file font. TTF dibuat di dalam aplikasi dengan outline piksel yang tajam dan tanpa celah: pakai di ukuran sama dengan tinggi huruf (mis. 9 px) atau kelipatannya agar tepinya tajam. Tidak ada yang diunggah.
8. **DDG Editor** (Document Design Game) — editor teks yang dibuat khusus untuk dokumen desain game (GDD). Pilih **Templat** atau langsung mengetik.
   - **Teks:** gaya *Paragraf / Judul 1–4 / Kutipan*, *Jenis font* (Sans-serif, Serif, Monospace, Display, Tulisan tangan), **Ukuran teks** dalam px (ketik angka, atau pakai A− / A+), **Ketebalan** (300 Tipis sampai 900 Hitam; banyak font hanya punya Normal dan Tebal, jadi tingkat di antaranya bisa tampak sama), *Jarak baris*, tebal / miring / garis bawah / coret, warna teks, warna sorot, dan rata teks. Kalau ada teks yang dipilih, perubahan berlaku untuk pilihan itu; kalau hanya ada kursor, berlaku untuk paragraf tempat kursor berada.
   - **Daftar:** poin, angka, dan **daftar centang** (ketuk kotaknya untuk mencentang, cocok untuk tugas), plus geser masuk / keluar (Tab dan Shift+Tab di dalam daftar).
   - **Blok desain game:** **Tabel** (untuk statistik dan balancing; tombol *+ Baris*, *+ Kolom*, *− Baris*, *− Kolom*, dan *Hapus tabel* muncul saat kursor ada di dalam tabel), **Kotak catatan** (*Catatan*, *Ide*, *Mekanik*, *Risiko*, *Tugas*: kotak berwarna dengan label; menu *Jenis kotak* muncul saat kursor ada di dalamnya), **gambar** (pilih file, tempel, atau seret; gambar pixel art kecil tetap tajam dan diperbesar dengan kelipatan bulat), tautan, dan garis pemisah.
   - **Templat:** **GDD Lengkap**, **Satu halaman**, dan **Lembar karakter / item**. Kalau dokumen sudah berisi teks, kamu memilih mengganti isinya atau menambahkan templat di akhir.
   - **Daftar isi** menampilkan judul-judulnya (ketuk satu untuk melompat ke sana), dan penghitung menunjukkan jumlah kata, karakter, serta waktu baca.
   - **Pengaturan Dokumen:** ukuran teks dasar, jarak baris, lebar halaman (**Penuh / Lebar / Sempit**), dan kertas (**Terang / Gelap**). Semuanya ikut tersimpan bersama dokumen dan dipakai di berkas unduhan.
   - **Simpan:** **Simpan** (Ctrl+S) menyimpan dokumen di IndexedDB, di browser ini (tidak ada yang diunggah), dalam folder **Dokumen DDG** yang juga tampil di Simpan & Buka. **Simpan salinan** membuat berkas baru. Daftar di bagian bawah tab membuka, mengganti nama, dan menghapus dokumen tersimpan. **Draf** disimpan otomatis saat kamu mengetik dan kembali setelah halaman dimuat ulang atau crash.
   - **Unduh:** **HTML** (satu halaman mandiri yang tampilannya sama dengan editor), **Markdown** (.md), **Teks** (.txt), **Cadangan** (.ddg.json, dibuka lagi di sini persis seperti semula), dan **Cetak / PDF** (membuka dialog cetak browser: pilih *Simpan sebagai PDF*). **Buka dari berkas** membaca cadangan, halaman HTML, atau berkas .md / .txt. Apa pun dari luar dibersihkan dulu: skrip, gambar dari internet, dan tautan berbahaya dibuang.
   - Catatan: Urungkan / Ulangi (Ctrl+Z / Ctrl+Y) mencakup pengetikan dan format, tetapi tidak mencakup tombol baris / kolom tabel dan mencentang kotak. Teks yang kamu tempel dari halaman web masuk tanpa warna dan font aslinya.
9. **Sound Studio** — buat lagu dan efek suara (SFX) untuk game-mu. Tab ini punya dua bagian, **Lagu** dan **SFX**. Di bagian atas: nama proyek, **Baru**, **Simpan**, **Simpan salinan**, **Buka dari berkas…**, dan **Lagu contoh** (lagu pendek buatan sendiri untuk dicoba).
   - **Putar:** **Putar / Jeda**, **Berhenti**, **Ulang** (bar yang diatur di *Ulang dari bar / sampai bar*), **Metronom**, posisi yang berjalan, dan osiloskop kecil. *Tempo* 30–300 BPM; *Volume utama* mengatur keseluruhan suara. Ketuk **penggaris** di atas piano roll untuk mulai dari titik itu. Kamu tetap bisa mengedit selagi lagu diputar. Spasi = putar / jeda.
   - **Track:** sampai 8. **Track nada** punya suara (*Kotak 50%*, *Pulsa 25%*, *Pulsa 12,5%*, *Segitiga*, *Gergaji*, *Sinus*, *Organ*, *Derau (noise)*); **track drum** punya 8 drum (kick, snare, hi-hat tutup dan buka, clap, tom rendah dan tinggi, crash). Tiap track punya *Volume*, *Kiri – kanan*, **M** (bisukan) dan **S** (solo); track nada juga punya amplop volume (*Attack / Decay / Sustain / Release*) dan *Vibrato*. Track bisa digandakan, dikosongkan, atau dihapus, dan **Geser semua nada track ini** menaikkan atau menurunkan track nada sebanyak 1 atau 12 semiton.
   - **Piano Roll** (C1 – B6): dengan **Gambar**, ketuk sel kosong untuk membuat nada dan seret ke kanan untuk memanjangkannya; ketuk nada untuk memilihnya, seret untuk memindahkannya, seret ujung kanannya untuk mengubah panjang. Alat lainnya: **Hapus**, **Pilih**, dan **Geser**. Di layar sentuh, dua jari selalu menggeser tampilan; roda mouse juga menggesernya dan Ctrl + roda memperbesar. **Lebar** dan **Tinggi** memperbesar atau memperkecil grid. Ketuk tuts piano untuk mendengarnya. Atur *Panjang nada baru* (1–16 step), *Akor* (mayor, minor, sus4, diminished, septima, minor 7, oktaf) dan *Kekuatan nada baru*, atau nyalakan **Kunci ke skala**. Nada yang terpilih bisa diubah (nada, mulai, panjang, kekuatan), digandakan, atau dihapus (tombol Delete). **Urungkan / Ulangi** (Ctrl+Z / Ctrl+Y) menyimpan 60 langkah.
   - **Pengaturan Lagu:** *Jumlah bar* (1–64, paling banyak 2048 step seluruhnya), *Ketukan per bar* (2–8), *Resolusi grid* (1/8, 1/16, atau 1/32), *Swing* (0–60%), *Nada dasar* dan *Skala* (nada dalam skala diberi warna di piano roll), serta efek utama **Gema (echo)** (jeda, pengulangan, campuran) dan **Reverb**. Kalau suatu perubahan akan membulatkan atau memotong nada (mis. grid lebih kasar atau bar lebih sedikit), kamu ditanya dulu, dan bisa diurungkan.
   - **Alat Bar:** salin sekelompok bar ke tempat lain (semua track, atau hanya track terpilih), atau kosongkan sekelompok bar. Kalau salinan melewati akhir lagu, jumlah bar bertambah sendiri.
   - **Unduh Lagu:** **WAV** (44100 / 48000 / 22050 Hz, 16 atau 8 bit, stereo atau mono, dengan pilihan *Loop mulus* yang melipat ekor gema ke awal, dan *Normalisasi volume*), **MIDI** (.mid berisi semua track, drum di kanal 10; swing tidak ikut ditulis), dan **Cadangan Proyek** (.sndproj.json). WAV memakai track yang tidak dibisukan (dan solo, kalau ada). Lagu sampai 10 menit bisa dirender.
   - **Buka dari berkas…** membaca berkas **MIDI** (.mid / .midi), berkas **.sfxr**, Cadangan Proyek, atau `sfx-bank.json`. Untuk MIDI: nada dibulatkan ke grid 1/16, dipakai sampai 8 track (kanal 10 menjadi track drum, nada drumnya dipetakan ke 8 drum), nada di luar C1 – B6 dipindah per oktaf, dan hanya tempo yang pertama yang dipakai. Pewaktu SMPTE belum didukung.
   - **SFX:** generator suara bergaya sfxr. **Koin**, **Tembakan**, **Ledakan**, **Power-up**, **Kena pukul**, **Lompat**, **Pilih / klik**, dan **Acak** membuat titik awal, dan **Mutasi** mengubah suara yang sekarang sedikit saja. Bentuk gelombang digambar, dan *Putar otomatis saat diubah* memutarnya setiap kali ada perubahan. **Parameter:** *Gelombang* (Kotak, Gergaji, Sinus, Derau) dan 22 slider dalam kelompok (Amplop, Frekuensi, Vibrato, Arpeggio, Lebar pulsa, Ulang suara, Filter, Phaser), ditambah *Volume*, *Normalisasi*, dan *Putar terbalik*. **Urungkan / Ulangi** menyimpan 40 langkah.
   - **Bank SFX:** simpan sampai 64 suara dalam daftar. Untuk tiap suara: **Putar**, **Muat** (ke editor), **Ganti isi** (dengan suara yang sekarang), **Ubah nama**, **Unduh WAV**, dan **Hapus SFX**. Bank ikut tersimpan bersama proyek.
   - **Unduh SFX:** **WAV** (44100 / 22050 / 11025 Hz, 16 atau 8 bit), **.sfxr** (bisa dibuka di alat sfxr), dan **seluruh bank** sebagai satu ZIP (satu WAV per suara ditambah `sfx-bank.json`).
   - **Simpan:** **Simpan** menyimpan seluruh proyek (lagu dan semua SFX) di IndexedDB, di browser ini (tidak ada yang diunggah), dalam folder **Audio** yang juga muncul di Simpan & Buka. **Simpan salinan** membuat berkas baru, dan daftar di bawah tab ini membuka, mengganti nama, dan menghapus proyek tersimpan. **Draf** tersimpan otomatis selagi kamu bekerja dan kembali setelah refresh atau macet (Mode Pemulihan tidak mencakupnya). Pemutaran berhenti saat kamu meninggalkan tab atau halaman disembunyikan. Semuanya dibuat di dalam aplikasi dengan Web Audio bawaan browser: tanpa library, tidak ada yang diunggah.
10. **Gabung** — muat **2 spritesheet atau lebih** (**+ Tambah Spritesheet**, sampai 12; ↑ ↓ mengubah urutan, × menghapus satu) lalu gabung horizontal, vertikal, overlay, atau tambahkan frame-nya. Di **Append Frames** tiap spritesheet punya *Lebar / Tinggi frame* sendiri (dan menampilkan jumlah frame-nya), dan hasilnya bisa diexport bersama JSON metadata.
11. **Export** — isi **Nama file**, pilih **PNG / JPG / WebP** (JPG dan WebP punya slider kualitas; JPG mengisi area transparan dengan warna latar pilihanmu), lalu unduh spritesheet, **semua frame jadi satu ZIP** (atau satu per satu), atau JSON metadata (posisi dan nama frame). Kalau frame berubah setelah sheet dibangun, Export membangunnya ulang otomatis.
   **Export animasi** (kartu kedua di tab Export): buat **GIF**, **WebP animasi**, atau video **MP4** dari frame. Atur *Kecepatan* (1–60 FPS), *Ukuran* (1×–8×, skala bilangan bulat), *Mode putar* (**Ulang**, **Bolak-balik**, **Sekali**), *Dari / Sampai frame* (kosong = pertama / terakhir), dan **Latar transparan** (GIF dan WebP) atau warna latar. GIF memakai paling banyak 255 warna dan transparansi ada-atau-tidak; WebP mempertahankan transparansi penuh (kualitas 100 = paling tajam); MP4 tidak punya transparansi dan butuh browser dengan WebCodecs (Chrome, Edge, atau Safari terbaru). Frame yang ukurannya berbeda diletakkan di tengah. Nama file: `nama_anim.gif` / `.webp` / `.mp4`. Semua dibuat di dalam aplikasi: tanpa library, tidak ada yang diunggah.

12. **Simpan & Buka** — simpan pekerjaanmu di browser ini dan buka lagi nanti. Isi **Nama**, pilih **Folder** (atau biarkan otomatis), lalu tekan **Simpan Animasi** (frame beserta layer dan nama, plus pengaturan Player dan export animasi), **Simpan Spritesheet** (sheet hasil bangun atau gabung beserta pengaturannya), **Simpan Font** (seluruh Font Creator), **Simpan Dokumen DDG** (dokumen DDG Editor), atau **Simpan Proyek Audio** (Sound Studio: lagu dan bank SFX). Berkas tampil sebagai folder: **Animasi**, **Spritesheet**, **Font**, **Dokumen DDG**, **Audio**, dan folder buatanmu lewat **+ Folder Baru**. Buka folder, lalu **Buka**, **Timpa** (dengan pekerjaanmu sekarang), **Ubah nama**, **Pindah**, atau **Hapus** berkas. Membuka animasi memberi pilihan mengganti frame yang sekarang atau menambahkannya di akhir; spritesheet tersimpan bisa dibuka ke tab Spritesheet / Export atau dikirim ke tab Gabung.
    **Mode Pemulihan:** aplikasi menyimpan otomatis beberapa detik setelah kamu berhenti bekerja. Kalau halaman tertutup saat ada pekerjaan yang belum disimpan, saat dibuka lagi kamu ditawari **Pulihkan**, **Buang**, atau **Lewati** (Lewati menjeda simpan otomatis; kartu **Mode Pemulihan** di tab ini memulihkan atau membuangnya nanti). Slot di tab Gabung tidak ikut dicadangkan, hanya hasil gabungannya.
    **Penyimpanan:** semuanya ada di IndexedDB di browser ini (tidak pernah diunggah) dan dibatasi **1 GB**. Melewatinya butuh izinmu: **Ubah Batas…** (atau pertanyaan saat simpanan tidak muat) menawarkan 2, 4, 8, atau 16 GB setelah kamu konfirmasi, dan meminta browser menjaga data tetap permanen. Menghapus data situs di browser juga menghapus berkas tersimpan.

**Pixelated vs Smoothed** (di menu). *Pixelated* tidak pernah mencampur warna: paling cocok untuk pixel art. *Smoothed* merata-ratakan warna saat diperkecil dan menghaluskan saat diperbesar: lebih cocok untuk foto/video. Pengaturan ini berlaku saat frame diekstrak atau sheet dibangun, jadi bangun ulang setelah mengubahnya.

**Pengaturan** (tombol roda gigi di bar atas, atau *Pengaturan…* di menu). **Bahasa** (ID / EN), **Mode** (Terang / Gelap), dan **Tema** ada di satu tempat. Untuk tema, pilih **Bawaan**, **Laut**, **Senja**, **Anggur**, **Mawar**, atau **Mono**, lalu ubah *Latar*, *Panel*, *Teks*, dan *Aksen* untuk membuat tema sendiri. Warna disimpan terpisah untuk mode Terang dan Gelap. **Bawaan** kembali ke warna awal aplikasi. Semua pilihan diingat di browser ini.

**Tips.** Untuk video pakai ukuran frame kecil (mis. 64–128 px). FPS lebih rendah = frame lebih sedikit dan rapi. Selama halaman terbuka, pekerjaan ada di memori; pakai **Simpan & Buka** untuk menyimpannya. Mode Pemulihan mengembalikan pekerjaan yang belum disimpan setelah refresh atau macet.

Kedelapan skrip adalah file biasa (bukan module) yang berbagi satu scope, jadi `index.html` harus memuatnya berurutan: `core.js`, `tabs.js`, `paint.js`, `extras.js`, `storage.js`, `ddg.js`, `sound.js`, `audio.js`. Tetap tanpa build.

## Jalankan lokal
Buka `index.html` di browser. Tidak perlu instal apa pun.

## Deploy ke GitHub Pages (untuk pemula)
1. Buat akun di github.com, lalu tekan **+ → New repository**. Beri nama (mis. `spritesheet-studio`), pilih **Public**, klik **Create repository**.
2. Klik **uploading an existing file** (atau **Add file → Upload files**). Unggah *isi* folder proyek (`index.html`, `style.css`, folder `js` beserta 8 file di dalamnya, `README.md`, `README.id.md`, `LICENSE`, `CHANGELOG.md`, `CHANGELOG.id.md`). Ekstrak ZIP dulu, jangan unggah ZIP-nya. Klik **Commit changes**.
   - **Jaga folder `js`.** Di komputer, seret *folder* `js` itu sendiri ke halaman unggah (bukan file-file di dalamnya). Kalau file dipilih atau diseret satu per satu, GitHub menaruhnya di folder utama, di luar `js`. Di HP halaman unggah tidak bisa membawa folder: pakai **Add file → Create new file**, ketik `js/core.js` sebagai nama (tanda garis miring membuat foldernya), tempel isinya, lalu commit; ulangi untuk tiap file.
   - **File terlanjur di luar `js`?** Buka file itu di repo, klik ikon pensil, lalu di kolom nama di atas ketik `js/` di depan namanya (jadi `core.js` menjadi `js/core.js`), kemudian **Commit changes**. File pindah ke dalam folder.
3. Buka **Settings → Pages**. Di *Build and deployment*, Source: **Deploy from a branch**, Branch: **main**, folder **/ (root)**, lalu **Save**.
4. Tunggu 1–2 menit. Situsmu: `https://<username>.github.io/<nama-repo>/`.

Untuk update nanti: buka file di repo, klik ikon pensil, edit, lalu commit — atau unggah ulang file dengan nama yang sama.
